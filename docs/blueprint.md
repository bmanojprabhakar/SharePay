# **App Name**: AuthFlow

## Core Features:

- Login Page: Visually appealing login page with username/password fields.
- Registration Page: Intuitive registration page to create new accounts with input validation.
- Forgot Password Page: Forgot password page with email input to reset password.
- Password Reset Confirmation Page: Confirmation page that navigates to the Login Page.
- Sign in with google: Enable user to sign in through google account

## Style Guidelines:

- Primary color: Soft violet (#B19CD9) to suggest a balance of creativity and seriousness.
- Background color: Light grey (#F0F0F0), providing a clean and unobtrusive backdrop.
- Accent color: Deep purple (#673AB7), offering a contrasting highlight for interactive elements.
- Body and headline font: 'Inter', a sans-serif font that is neutral and machined, provides legibility.
- Simple, line-based icons to represent input field types (e.g., user icon for username, lock icon for password).
- Add a placeholder for the text boxes with example value. It should also possess svg icons to view the password, etc.
- Clean and modern layout with a focus on usability. Input fields and buttons should be clearly labeled and easy to interact with.
- Subtle transitions and animations on button hovers and form input focus.
- Consistent Theming
- Mobile-First Design: The layout is fully responsive and optimized for mobile devices
- Enhanced Branding: The SharePay logo uses a gradient text effect and professional styling
- SharePay Branding: Add the SharePay logo and name prominently at the top
- Google Sign-In: Integrated Google OAuth button with authentic Google branding and colors
- Updated Color Theme: Switched to a beautiful bluish sky and green gradient theme throughout
- Copyright Footer: Added "© 2025 SharePay. All rights reserved." at the bottom
